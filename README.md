# Kaloweb

Platform pembuatan website profesional untuk bisnis Anda.

## Tentang Kaloweb

Kaloweb adalah platform jasa pembuatan website yang menyediakan solusi digital premium, mulai dari website custom, toko online, hingga landing page.

## Cara Menjalankan Secara Lokal

**Prerequisites:** Node.js

1. Install dependencies:
   ```
   npm install
   ```
2. Salin `.env.example` menjadi `.env` dan isi variabel yang dibutuhkan (Supabase URL & Key)
3. Jalankan aplikasi:
   ```
   npm run dev
   ```

## Tech Stack

- **Frontend:** React + TypeScript + Vite
- **Styling:** CSS Custom
- **Animasi:** Framer Motion
- **Backend/DB:** Supabase
- **Routing:** React Router DOM
